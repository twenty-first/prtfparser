prtfparser
=========
A parser for IBM's Print File Specifications
--------------------------------------------------
![build](https://github.com/twenty-first/prtfparser/actions/workflows/build.yml/badge.svg)

`prtfparser` is a parser for PRTF files, which are used on IBM i systems to specify report layouts.
A possible use for `prtfparser` would be to collect the information necessary to reimplement
RPG or COBOL reports in a different language or environment.

`prtfparser` is written in Java with the help of the [ANTLR parser generator](https://www.antlr.org/)
and is available from the Maven Central repository.
